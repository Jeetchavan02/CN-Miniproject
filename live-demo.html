How This Browser Timing Mechanism Works

The browser uses window.performance.getEntriesByType('resource') to inspect exact timestamp attributes populated by the browser engine:

const [entry] = performance.getEntriesByName(resourceURL);
const dnsTime = entry.domainLookupEnd - entry.domainLookupStart;
const tcpTime = entry.connectEnd - entry.connectStart;
const tlsTime = entry.secureConnectionStart > 0 ? entry.connectEnd - entry.secureConnectionStart : 0;
const ttfb = entry.responseStart - entry.requestStart;
const totalDuration = entry.duration;
